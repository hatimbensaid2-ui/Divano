# Dossier des ressources (assets) — DIVANO

Déposez vos fichiers PNG ici, **avec exactement ces noms**. Le thème les
référence automatiquement (et affiche un visuel de remplacement tant qu'un
fichier est absent). Vous pouvez aussi tout gérer depuis l'éditeur de thème
Shopify (Personnaliser) sans toucher aux fichiers.

> ⚠️ Shopify n'autorise pas de sous-dossiers dans `assets/`. Tous les fichiers
> doivent être à plat dans ce dossier.

## Logos
| Fichier                  | Usage                          |
|--------------------------|--------------------------------|
| `divano-logo-white.png`  | En-tête + pied de page (fond vert) |
| `divano-logo-black.png`  | Pages claires / favicon / impression |

| `category-sofas.png`         | Carte catégorie « Canapés »            |

| `category-tables.png`        | Carte catégorie « Tables »             |
